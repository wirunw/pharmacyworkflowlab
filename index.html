ทุก case ให้ครบทั้งสมการ: Prompt แบบ R–T–F, Context จำลองที่หน้าตาเหมือนของจริง, Model และ Tools ที่แนะนำ และจุดที่เภสัชกรต้องตรวจ

วิธีเล่นใน 30 นาที

  1. กลุ่มเลือก 1 workflow จากแผนที่ด้านล่าง
  2. กด คัดลอก Prompt + Context ของ Task 1 ไปวางในแอป AI ที่กลุ่มใช้ แล้วทำ Task ถัดไปในแชตเดิม
  3. หาจุดที่ AI ผิดหรือพลาดกับดักในข้อมูล แล้วค่อยกดดูเฉลย
  4. คุยกันว่าควรปรับ R, T หรือ F ตรงไหน แล้วรัน Round 2
  5. ติดป้ายแต่ละ task ว่าใครทำ และเลือก 1 task ที่ควรเป็น Skill ใช้ซ้ำ
