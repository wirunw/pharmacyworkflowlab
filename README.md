# Pharmacy Workflow Lab

ใช้ประกอบ Workshop **AI for Smart Pharmacy Executives 2026** (UHosNet) ช่วง Workflow Lab

เปิดใช้งาน: https://wirunw.github.io/pharmacyworkflowlab/
